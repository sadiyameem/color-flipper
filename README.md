# Color Flipper

# Description
This project let's users see different gradient color backgrounds by clicking a button.
It includes a dark mode that changes the text colors to white so it makes it easy to read the words.
This project was created by the use of HTML, CSS and JavaScript.

# Features
- A Button that generates differnet colors
- Shows the gradient color code
- Dark mode button
- Hover effects on the buttons

# Motivation
I created this project because I wanted to make something interactive and something that I really enjoy.

# Challenges and Learning
I learned how to make a interactive color generator with different colors each time.
A challege I faced was making it interactive and work the way I wanted.
